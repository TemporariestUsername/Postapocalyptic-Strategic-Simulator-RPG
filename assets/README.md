# Placeholder Assets (v0)

These are generated placeholder art assets for the GUI milestone.

## Regenerate

```bash
python scripts/build_placeholder_assets.py
```

## Contents

- `ui/icons/*.ppm` — action button icons
- `ui/panels/hud_bg.ppm` — basic HUD background swatch

The placeholders are intentionally simple and should be replaced by
final postapocalyptic art packs later.
